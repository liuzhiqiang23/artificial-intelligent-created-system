# 考场部署指南（上机开卷·另一台电脑 · 5 分钟版）

> 包根目录：exam-kit（U盘拷贝，全程免管理员权限可用；装 Python/tesseract 需要管理员则找老师）

## 第 0 步：开考先做的三件事（1 分钟）

1. 打开 `notes/期中速查表.md` —— 题型→脚本对照总表
2. U盘 whole 拷到考试机 **D 盘根目录**（保持 exam-kit 目录名不变，路径全相对）
3. 若考场有网：优先直接 `git clone https://gitee.com/liu-zhiqiang20030520/intelligent-production-system`（仓库里也有全套）

## 第 1 步：Python 环境（2 分钟）

- 机器有 Python 3.10+：直接用
- 没有或版本不对：双击 `scripts/tools/python-3.10.11-amd64.exe` 安装（勾 Add to PATH）
- 建议建 venv：
  ```
  python -m venv D:\exam-venv
  D:\exam-venv\Scripts\pip install --no-index --find-links=D:\exam-kit\wheels -r D:\exam-kit\scripts\requirements-freeze.txt
  ```
  （断网也能装：wheels 里是全部离线包。有网时可改用普通 `pip install -r`）

## 第 2 步：系统工具（1 分钟，只在做 PDF-unstructured / OCR 题时才需要）

- **poppler**：`scripts/tools/poppler/poppler-25.12.0/Library/bin` 加入 PATH
- **tesseract**：免安装直接用便携目录——设两个环境变量：
  - PATH 追加 `D:\exam-kit\scripts\tools\Tesseract-OCR`
  - 新建 `TESSDATA_PREFIX=D:\exam-kit\scripts\tools\tesseract-data`（中文包在这）
  - 注意：脚本 4-img-ocr/05/06/07 里写死的 `C:\Program Files\Tesseract-OCR` 路径，考场要改成上面便携路径（或现场用 `os.environ['PATH']` 那行的写法）
- PowerShell 一键设（当前会话）：
  ```
  $env:PATH += ';D:\exam-kit\scripts\tools\Tesseract-OCR;D:\exam-kit\scripts\tools\poppler\poppler-25.12.0\Library\bin'
  $env:TESSDATA_PREFIX = 'D:\exam-kit\scripts\tools\tesseract-data'
  ```

## 第 3 步：素材就位（30 秒）

脚本按原项目结构找素材，拷过去保持相对位置：
- `scripts/08~12.py` 找同级 `file1008/` → 把 `files/file1008` 拷到 scripts 旁边
- `scripts/01~07.py` 找 `files/`（PDF/图片）与 `imgs/` → 从 `files/0924files`、`files/imgs` 拷
- `scripts/0917/*.py` 找 `file/wiki.txt` 等 → 从 `files/0917file` 拷到 0917 目录旁的 file/
- 模型已在 `models/`（bge-small-zh 512维 / all-MiniLM 384维），**脚本已改相对路径，无需改代码**

## 第 4 步：跑题

- 格式加载题 → scripts/08~12（JSON/Office/Markdown/HTML/Docling）
- OCR 题 → scripts/05/06/07 + imgs
- 向量库题 → scripts/0917/：先 `2-zvec-minilm-save.py` 再 `2-zvec-search-no-llm.py`（免 ollama 保底版，输问题出 top3）；faiss 路线 `1-faiss-bge.py`
- 素材路径变了找不到文件 → 顺手改脚本头部的目录变量（都提出来了）

## 不依赖任何部署就能用的（开卷材料）

`notes/`：笔记 0910/0917/0924/1008 四份 PDF + 期中速查表（含口答八条、Docling 概念卡、在线 OCR 四平台对比）

本包不含（5.2GB 模型拷贝慢）。替代方案：检索结果直接打印即可证明"存储+检索"；生成环节用速查表口述流程。
