## 2. 格式加载·一页流（笔记1008 第4节核心）

```
JSON:    json库直读(dict精细控制) | JSONLoader(jq_schema=".", text_content=False) | JSONReader
Word:    UnstructuredWordDocumentLoader(需LibreOffice) | DocxReader(免依赖战) | docling DocumentConverter(免模型)
PPT:     UnstructuredPowerPointLoader(需LibreOffice, mode=single/elements/paged) | PptxReader
Excel:   UnstructuredExcelLoader(需LibreOffice) | DoclingReader | openpyxl手读
Markdown: UnstructuredMarkdownLoader | MarkdownReader | SimpleDirectoryReader直读
HTML:    WebBaseLoader(在线) / UnstructuredHTMLLoader / BSHTMLLoader(bs4) | SimpleWebPageReader / BeautifulSoup / html2text
```

**jq 语法速记**：`.` 整个文档｜`.[0]` 第一个元素｜`.[].content` 每条的 content 字段（可在 play.jqlang.org 测）

**play.jqlang.org 用法（jq 官方练习场，10-08 老师点名）**：左边贴 JSON，上方输入框敲 jq 表达式，右边立即出结果。用 `scripts/file1008/pages.json` 实测：

| jq_schema | 含义 | 实测结果 |
|---|---|---|
| `.` | 整个文档当 1 条 | **1 个 Document**（笔记示例用的） |
| `.[]` | 逐条拆开 | **3 个 Document**（每条一个） |
| `.[].title` | 每条的标题 | ["智能生成系统期中复习","向量检索要点","OCR 要点"] |
| `.[].content` | 每条的内容 | 检索入库就取这个字段 |
| `.[0]` / `.[1:]` | 第1条 / 第2条起 | 1 条 / 2 条 |
| `map(.title)` | 收集成数组 | 1 个 Document（内含数组） |

**追问点**：为什么 `jq_schema='.'` 得 1 个文档而 `'.[]'` 得 3 个？——jq 表达式产生几条结果，JSONLoader 就产出几个 Document。

**JSON 在线工具（老师 10-08 补发）**：ccjson.com（格式化/压缩/校验/转义，还能转 Python/Java 代码、XML/YAML/CSV）｜bejson.com/jsonviewernew（JSON 可视化查看器）。断网时用本地：`python -m json.tool 文件.json`

**file_extractor 是什么**：LlamaIndex SimpleDirectoryReader 的参数，"遇到 .xx 后缀用哪个读取器"的字典，如 `{".pdf": pdf_reader, ".json": JSONReader()}`。

## 3. Docling（笔记1008 第5节——新面孔，老师必考概念题）

- **一句话**：IBM 开源的文档智能解析库，把 PDF/DOCX/PPTX/XLSX/图片/音频统一转成 DoclingDocument，导出 Markdown/HTML/JSON，RAG 预处理利器。
- **四特性**：多格式、深度结构理解（布局/表格/公式/阅读顺序）、统一文档表示、集成 OCR 与 LangChain/LlamaIndex。
- **核心对象**：`DocumentConverter` + `format_options={InputFormat.PDF: PdfFormatOption(pipeline_options)}`，`pipeline_options.artifacts_path=本地模型路径`；`convert(路径).document.export_to_markdown()/text/html()`。
- **Word/PPT/Excel 转换不需要模型路径**：`DocumentConverter()` 裸建即可 —— 考场快速得分点。
- PDF 需下载 1-2G 模型（HF_ENDPOINT=https://hf-mirror.com 镜像）；模型默认在 ~/.cache/docling/models。
- 与 LlamaIndex 集成：`DoclingReader(pipeline_options=...)` 或 `DoclingReader(converter=...)`；**自定义批量方法是最稳的**（逐文件 convert → export_to_text → Document，try/except 容错）。
- 图片识别走 TesseractOcrOptions(lang=["chi_sim","eng"])，但笔记原话：Docling 的 TesseractOcr 效果**不如**直接用 tesseract 命令。

## 5. 高频口答八条

1. **Document 结构**：page_content(正文) + metadata(来源/页码/文件名)
2. **为什么要切分**：嵌入与检索有长度限制；碎→丢上下文，大→检索不准
3. **维数谁定**：嵌入模型定，BGE-small-zh=512，MiniLM=384；zvec Schema 写死，存查同模型
4. **IndexFlatL2**：faiss 精确暴力检索（L2 欧氏距离），数据小用它最稳
5. **fast vs hi_res**：fast 不下载模型纯文本提取；hi_res 要 HuggingFace 模型（一般下不动）
6. **single/elements/paged**：整篇一份 / 按逻辑元素(带Title等分类) / 按物理页
7. **lazy_load**：用到才读，大文档省内存
8. **pytesseract vs tesseract**：遥控器 vs 电视机；UnstructuredImageLoader 只认 PATH
