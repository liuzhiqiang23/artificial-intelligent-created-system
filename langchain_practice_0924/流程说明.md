# 0924 非文本文件实践 · 流程说明（通俗版）

> 用途：上课演示前的"讲给自己听"版流程说明。说「调出」时连同环境检查一起展示。

## 一句话版本

这周的作业是**让电脑"读懂"不是纯文字的文件**——PDF 和图片。PDF 要把里面文字抠出来，图片要"看图认字"（OCR），然后交给之前学的那套 LangChain / LlamaIndex 流程去处理。

## 老师发来的三样东西

1. **`笔记0924.pdf`**——任务书，等于作业清单：PDF 怎么读、图片怎么认字，每样都给了两种框架（LangChain 和 LlamaIndex）的写法
2. **`poppler-25.12.0-0.zip`**——一个 **PDF 工具箱**（解压后是一堆命令行小程序，比如把 PDF 某一页"拍成"图片的 `pdftoppm`）
3. **`tesseract-ocr` 安装包**——**OCR 引擎**，真正"看图识字"的那个软件

## 为什么非要这两个工具？（本次最该理解的点）

**关于 tesseract**：Python 里我们用的是 `pytesseract`，但它只是个**遥控器**，自己不会认字；真正干活的是系统里装的 **tesseract（电视机）**。遥控器按下去必须有电视机接着，所以引擎必须装在系统里、还得让系统找得到它——这就是为什么要配 PATH 环境变量。

**关于 poppler**：Unstructured 那套解析库在处理 PDF 时，遇到扫描件或者要精细分析版面，会先把 PDF 页**转成图片**再分析（这一步由一个叫 `pdf2image` 的中间件负责），而 `pdf2image` 自己也不会转——它调用的是 **poppler 里的命令行工具**。所以 poppler 不装，Unstructured 处理 PDF 就会断在中间环节。

理解了这层"谁调用谁"，任务书里那一长串安装说明就不难懂了。

## 实际部署流程（按执行顺序）

1. **poppler 解压到 D 盘**——`D:\poppler`（大文件全放 D 盘是铁律）
2. **检查 tesseract，发现本机早已安装**（v5.4.0），但**只有英文语言包**——中文识别会失败。补上简体中文：语言包放 `D:\tesseract-data`，用环境变量 `TESSDATA_PREFIX` 告诉 tesseract"语言包在这儿"。**免管理员方案**，不往系统目录写文件
3. **把两个工具加进 PATH**——任何程序（包括 PyCharm 里的脚本）都能直接调用它们
4. **装 Python 侧依赖**——PyMuPDF、langchain_unstructured、pytesseract、pdf2image、llama-index-readers-file 等一整套
5. **造演示素材**——老师真素材未到，自制：中文数据报表图、英文报表图、中文游戏介绍图各一张；PDF 暂用上节课任务书顶替。真素材到位后替换
6. **把任务书代码写成 5 个可运行脚本**——任务书是 Mac 版零散片段，逐段改成 Windows 版完整脚本
7. **五个脚本逐个实测**——PDF 三种读法、图片三种 OCR 方式全部出结果，中文识别一字不差（"2026年9月 华东区销售额: 128万元"）
8. **修坑**：`UnstructuredImageLoader` 内部**只认 PATH、不认 pytesseract 设置的路径**——不加环境变量必报 TesseractNotFoundError。任务书 Mac 版那行 `PATH += ':/opt/homebrew/bin'` 就是干这个的，Windows 版已对应补上
9. **同步仓库**——Gitee 已推，GitHub 网络原因待补
10. **重启 PyCharm**——环境变量是新的，已开着的 PyCharm 不自动认，必须重启；顺手配好 5 个一键运行配置

## 上课演示对照表

| 脚本 | 演示的"能力" | 通俗说 |
|---|---|---|
| 1-pdf-langchain | PyPDF 读 PDF | 老老实实一页一个文档 |
| 2-pdf-llamaindex | PyMuPDF 读 PDF | 同一件事，LlamaIndex 的写法 |
| 3-pdf-unstructured | Unstructured 三种用法 | 不光抠文字，还分得出"标题/列表/正文" |
| 4-img-ocr | 图片认字三种写法 | 中文图、英文图、自己封装识字工具类 |
| 5-img-llamaindex-ocr | OCR + 检索 | 图认清字后，问"华东区销售额多少"，答得出来 |

演示方式二选一：**PyCharm 点绿三角**（每个脚本都配好运行项）或**命令行跑**（我按 1→5 顺序跑完贴输出）。任务书无大模型环节，全部秒级出结果（5 号含 BGE 加载约 20-30 秒）。
